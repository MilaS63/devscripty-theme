# DevScripty Core

Custom code for the staging build (staging.devscripty.org) of devscripty.org (WordPress + Breakdance).

## What's inside
- Custom PHP functions and hooks
- Custom CSS and JS for Breakdance sections
- Exports of Breakdance templates (in /exports)

## Stack
WordPress, Breakdance, PHP, JavaScript, CSS, WP-CLI
